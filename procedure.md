<b>Note: </b> This is a VR-based experiment; in the simulation, you can learn from scratch how to download the APK and use VR, while the Procedure section explains the actual lab experiment steps as performed in the Virtual Reality (VR) Lab. <br>

<h2>Actual vs Virtual Reality Lab Procedure</h2>

<h3 style="text-decoration:none;">1. Power Setup :</h3>

<b>Actual (Physical Wiring)</b><br>
Connect the DC Power Supply to the trainer kit terminals (Vcc and GND) using physical wires. Ensure the polarity is correct to avoid damaging the chip.<br><br>

<b>Virtual Reality (VR) Lab Procedure</b><br>
The virtual battery (power source) is grabbed and connected to the circuit rails (0:24, 0:44), which powers the entire virtual system.

<hr>

<h3 style="text-decoration:none;">2. Circuit Component Placement :</h3>

<b>Actual (Physical Wiring)</b><br>
Insert the IC chip (e.g., the 7408 AND gate) carefully onto the breadboard or trainer kit. Connect physical wires from the power rails to the appropriate Vcc and GND pins on the chip.<br><br>

<b>Virtual Reality (VR) Lab Procedure</b><br>
The user grabs the virtual AND Gate and Indicator Light (bulb) and places them on the virtual table (0:26–0:32). Magnetic snapping ensures components connect logically.

<hr>

<h3 style="text-decoration:none;">3. Logic Input Wiring :</h3>

<b>Actual (Physical Wiring)</b><br>
Connect the physical input switches (A and B) to the designated input pins of the logic gate IC using short, clean wires.<br><br>

<b>Virtual Reality (VR) Lab Procedure</b><br>
The user uses the controller to grab virtual wire connectors and link the power source, inputs (implicit switches/source blocks), and the AND Gate together (0:46–1:12).

<hr>

<h3 style="text-decoration:none;">4. Logic Output Wiring :</h3>

<b>Actual (Physical Wiring)</b><br>
Connect the output pin of the IC to a physical current-limiting resistor and then to an LED indicator to display the output state.<br><br>

<b>Virtual Reality (VR) Lab Procedure</b><br>
The user connects the virtual AND Gate’s output to the Indicator Light (bulb) (1:13–1:17).

<hr>

<h3 style="text-decoration:none;">5. Verification (Truth Table) :</h3>

<b>Actual (Physical Wiring)</b><br>
Manually flip the physical input switches (A=0, B=0, A=1, B=0, etc.) and observe the state of the output LED (ON/OFF) to fill out the Truth Table.<br><br>

<b>Virtual Reality (VR) Lab Procedure</b><br>
The user virtually toggles the inputs (implicit in the demonstration, causing the bulb to light up) and observes the virtual light bulb (ON = Logic 1, OFF = Logic 0) to verify the Truth Table (1:13–1:17).

<hr>

<h3 style="text-decoration:none;">6. Iteration (OR Gate) :</h3>

<b>Actual (Physical Wiring)</b><br>
Remove the AND gate IC, insert the OR gate IC (e.g., 7432), and rewire the inputs and output, repeating the process while managing risk of incorrect wiring.<br><br>

<b>Virtual Reality (VR) Lab Procedure</b><br>
The user can instantly swap or build a parallel circuit with the OR Gate component (1:46–1:55), immediately testing its different logical behavior in the same setup.
